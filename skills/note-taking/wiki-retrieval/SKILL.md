# Wiki Retrieval — Second Brain Knowledge Access

Consult the Obsidian Second Brain wiki (04-Wiki/) before starting technical work or answering domain questions. The wiki contains 130+ pages of curated knowledge extracted from study sessions.

## When to Use

- Before any technical task: search the wiki for relevant existing knowledge
- When the user asks about a topic that might have been previously studied
- When you need context about tools, frameworks, or concepts the user has learned

## Wiki Location

The vault path is set by OBSIDIAN_VAULT_DIR (check `~/.hermes/.env`).
Default: `~/obsidian/memoribro`

Structure:
- `04-Wiki/index.md` — full catalog of all wiki pages with summaries
- `04-Wiki/Concepts/*.md` — concept pages (architectural patterns, frameworks, techniques)
- `04-Wiki/Entities/*.md` — entity pages (tools, people, projects, platforms)

## Retrieval Steps

1. **Quick scan**: Read `$OBSIDIAN_VAULT_DIR/04-Wiki/DIGEST.md` — compact summary of all pages (~5K tokens)
2. **Keyword search**: `search_files(pattern="your topic", path="$OBSIDIAN_VAULT_DIR/04-Wiki")` 
3. **Read relevant pages**: `read_file` on matched wiki pages for full content
4. **Apply knowledge**: Use the retrieved context to inform your response

The DIGEST.md is auto-generated by sync-second-brain.sh (Pass 4.6) after every wiki ingest.

## Example

```
# Step 1: Check what's in the wiki about "microkernel"
search_files(pattern="microkernel", path="~/obsidian/memoribro/04-Wiki")

# Step 2: Read the matched page
read_file(path="~/obsidian/memoribro/04-Wiki/Concepts/Microkernel Agent Architecture.md")

# Step 3: Use that knowledge in your response
```

## Page Format

Each wiki page has YAML frontmatter:
```yaml
---
title: Page Title
type: concept | entity
category: Topic Category
tags: [tag1, tag2]
summary: One-sentence summary
sources: [[Source Note Name]]
updated: 2026-MM-DD
---
```

## Pitfalls

- Wiki pages may have been generated by LLM — cross-check critical facts
- Check `04-Wiki/log.md` for ingest history if unsure about a page's provenance
- If OBSIDIAN_VAULT_DIR is not set, default to `~/obsidian/memoribro`
